# 选调生去向数据 · 录入说明

配套文件：**`去向数据录入模板.csv`**（同一个目录下）

一句话：**一个人一行，共 10 列；姓名必填，去向单位尽量填，其余尽力而为。**

---

## 一、怎么填

1. **双击**用 Excel 或 WPS 打开 `去向数据录入模板.csv`。
   > 不要用「记事本」打开再另存，那样会改变文件编码，中文会变成乱码。
2. **先删掉第 2 行的示例数据**（张三那一行）。
3. 从**第 2 行**开始逐行填写，**一个人一行**。
4. 填完保存即可。**`.xlsx` 和 `.csv` 都能收，不用特意转换格式。**

### 格式要求（请务必遵守）

| 要求 | 说明 |
| --- | --- |
| **表头只留一行** | 模板只有一行中文表头。如果你自己加了一行英文表头，会被当成一条数据，请删掉 |
| **一人一行** | 不要把两个人写在同一行 |
| **不要用合并单元格** | 合并单元格会导致后面所有列错位 |
| **单元格内不要按回车换行** | 那会把这一行拆成两行 |
| **姓名列不要留空行** | Excel 里看起来是空行，读取时可能变成一条空记录 |
| **不要修改列名** | 列名是我识别字段的唯一依据，改了就认不出来 |
| **列的顺序可以调** | 按你的习惯排就行，我按列名认，不按位置 |

---

## 二、列说明

共 10 列。**只有「姓名」必填，其余 9 列都可以留空**——留空不会导致导入失败，只是那一列不进入对应统计。

| 列名 | 重要程度 | 填写要求 | 示例 |
| --- | --- | --- | --- |
| **姓名** | ⭐ **必填** | 中文全名，不要带空格 | 张三 |
| **去向单位** | ⭐⭐ **强烈建议** | 完整单位名称。**最好带上省名/市名**（下面第三节会讲为什么） | 中共山西省大同市委组织部 |
| **学院** | 建议填 | 学院**全称**，不要写简称 | 信息工程学院 |
| **专业** | 建议填 | 专业**全称** | 计算机科学与技术 |
| **城市** | 建议填 | 城市**带后缀的全称** | 大同市 |
| **省份** | 建议填 | 省级行政区**全称** | 山西省 |
| **届别** | 建议填 | 「XXXX届」或「XXXX级」，**整列统一用一种** | 2024届 |
| **学历** | 建议填 | 本科 / 硕士研究生 / 博士研究生 | 硕士研究生 |
| **岗位** | 选填 | 具体岗位/职务/职级 | 四级主任科员 |
| **备注** | 选填 | 数据来源、特殊情况说明，方便日后核对 | 摘自2024年1月5日山西选调分享交流会 |

> 「去向单位」是**做统计最重要的字段**——省份分布、城市排名、单位统计都靠它。填得越全，统计越准。

## 三、好消息：省份、城市我可以自动补

如果「省份」「城市」没填，我可以**从「去向单位」里自动推断出来**。实测效果：

| 去向单位 | 自动补出的省份 | 自动补出的城市 |
| --- | --- | --- |
| 中共山西省大同市委组织部 | 山西省 | 大同市 |
| 广东省深圳市人民政府 | 广东省 | 深圳市 |
| 四川省成都市委组织部 | 四川省 | 成都市 |
| 新疆维吾尔自治区乌鲁木齐市…… | 新疆维吾尔自治区 | 乌鲁木齐市 |
| **兰州市委组织部** | **补不出来** ❌ | 兰州市 |

**规则：去向单位里写了省名，省份就能补出来。**

所以想省事的话，**「去向单位」这一列填完整、带上省名**，省份和城市不填也行。

## 四、取值规范

下面几条是最容易出错、也最影响统计结果的地方，**请务必按规范写**。

### 1. 省份 —— 必须写全称

| ❌ 不要这样写 | ✅ 要这样写 |
| --- | --- |
| 山西 | 山西省 |
| 广西 | 广西壮族自治区 |
| 内蒙古 | 内蒙古自治区 |
| 新疆 | 新疆维吾尔自治区 |
| 宁夏 | 宁夏回族自治区 |
| 西藏 | 西藏自治区 |
| 北京 | 北京市 |

原因：「山西」和「山西省」在系统里会被当成两个不同的省份，统计时会分成两行。

### 2. 城市 —— 必须带后缀

| ❌ 不要这样写 | ✅ 要这样写 |
| --- | --- |
| 中山 | 中山市 |
| 大理 | 大理白族自治州 |
| 延边 | 延边朝鲜族自治州 |
| 昆明 | 昆明市 |

直辖市（北京／上海／天津／重庆）的「省份」和「城市」填同一个即可，例如都填 `北京市`。

### 3. 学院 —— 写全称

| ❌ 不要这样写 | ✅ 要这样写 |
| --- | --- |
| 信工 | 信息工程学院 |
| 法院 | 法学院 |
| 经院 | 经济学院 |

### 4. 学历 —— 几种写法都能识别

系统会自动归并，所以下面这些都可以：

| 你写的 | 系统归为 |
| --- | --- |
| 本科 / 学士 | 本科 |
| 硕士研究生 / 研究生 | 硕士 |
| 博士研究生 | 博士 |

直接写「硕士研究生」这种最完整的形式最稳妥。

### 5. 届别 —— 整列统一

「2024届」和「2024级」系统都能认，但**请在一份文件里只用一种**，不要一半写「届」一半写「级」。

## 五、常见错误

| 现象 | 后果 | 正确做法 |
| --- | --- | --- |
| 保留了两行表头（中文 + 英文） | 正常情况下第二行会被自动跳过；但建议只留一行，省得自己排查 | 只留一行中文表头 |
| 用记事本打开后另存 | 中文全部变成乱码 | 用 Excel／WPS 打开并保存 |
| 单元格里按了回车换行 | 这一行被拆成两行，后面的列全部错位 | 一个单元格只写一行 |
| 用了合并单元格 | 合并后的列全部错位 | 拆开，每格独立填写 |
| 一格里写了两个人 | 检索时查不到其中任何一个人 | 一人一行 |
| 省份写简称、城市漏后缀 | 统计图里同一地区被拆成两条 | 按第四节规范写 |
| 修改了列名 | 该列数据全部丢失 | 列名原样保留 |

## 六、空字段会有什么后果（请了解一下）

只填「姓名」的记录，**能被检索到，但不会出现在统计图里**。

举一个实测的例子：如果有 3 个人只填了姓名和学历、**「去向单位」和「岗位」都是空的**，结果是：

- ✅ 这 3 个人**姓名可以正常检索到**
- ❌ 他们**不会出现在**省份地图、城市排行、学院分布等统计图里
- ⚠️ 他们会被算进岗位分类里的「**其他**」一项（因为没填去向单位，系统无法判断行业），
  让「其他」类的数字虚高

**结论：「去向单位」这一列最值得花力气填。** 实在不知道去向，就留空，照样交——总比漏掉一个人好。

## 八、填完之后

把文件发回给系统负责人即可，**不需要自己导入数据库**。

**建议文件名起得有含义**，例如 `2026届-山西选调.xlsx`。文件名会成为这批数据在系统里的**来源标识**，方便日后追溯和撤销。

### 系统负责人导入方式

```powershell
# 先看报告（不写库）：能导入多少条、哪些行与库里已有记录重复
python scripts/import_records.py 2026届-山西选调.xlsx --dry-run

# 确认后正式写入
python scripts/import_records.py 2026届-山西选调.xlsx
```

- 默认**跳过与库里已有记录重复的行**（同姓名 + 同一单位，或同姓名 + 同届别 + 同省/市），
  想全量保留就加 `--keep-duplicates`。
- 同一份文件重复导入不会产生重复数据（每次先清掉该文件上一次的导入结果）。
- 导入结果会存一份快照到 `data/manual/imported/`，重建数据库时会自动重放，不用担心 `--reset` 丢数据。
